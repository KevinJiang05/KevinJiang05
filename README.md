北京信息科技大学计算机科学与技术专业本科生，主要参与水下机器人相关软件研发，
工作涉及计算机视觉、地面站、控制系统与实际设备联调。

相比只完成可演示的原型，我更关注系统能否稳定运行、问题能否定位，
以及修改和实验能否复现。

- QGroundControl 定制及低延迟视频链路

## 项目

### [DeepShark View Studio](https://github.com/KevinJiang05/DeepSharkViewStudio)

**技术：** Python · PySide6 · OpenCV · FFmpeg

面向水下机器人多相机系统的桌面开发工具，覆盖实时预览、相机标定、
投影实验、环视拼接、运行诊断与 QGC 视频输出。

### [QGC for GRobot](https://github.com/KevinJiang05/QGC_for_GRobot)

**技术：** C++ · Qt/QML · MAVLink · QGroundControl

基于 QGroundControl 的 DeepShark 水下机器人定制地面站，
主要涉及多路视频、机器人状态展示、控制功能及设备联调。
